# VDB_DSAConquest

Personal DSA practice repo, combining two learning tracks: the **Code io Tamil DSA** video series and the **freeCodeCamp 49-hour** Data Structures & Algorithms course (plus related LeetCode problems).

Organized by **topic** (`Arrays`, `BigONotation`, ...) rather than by day, since concepts often span multiple sessions.

## Structure

Each topic folder contains subfolders based on the type of practice:

* `Local/` — code and implementations from the **Code io Tamil** DSA learning video series
* `HandsOn/` — code and notes from the **freeCodeCamp 49-hour** DSA course
* `LeetCode/` — related LeetCode problems, organized by difficulty:

  * `Easy/`
  * `Medium/`
  * `Hard/`

Example:

```text
Arrays/
├── Local/
└── LeetCode/
    ├── Easy/
    ├── Medium/
    └── Hard/
```

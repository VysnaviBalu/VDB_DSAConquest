# VDB_DSAConquest

Personal DSA practice repo, combining two learning tracks: the **Code io Tamil DSA** video series and the **freeCodeCamp 49-hour** Data Structures & Algorithms course (plus related LeetCode problems).

Organized by **topic** (`Arrays`, `BigONotation`, ...) rather than by day, since concepts often span multiple sessions. Each topic folder contains two subfolders for the two learning tracks:

## Structure
- `Topic/` — one folder per DSA concept (e.g. `Arrays`, `BigONotation`)
  - `Local/` — code and notes from the **Code io Tamil** DSA learning video series
  - `HandsOn/` — code and notes from the **freeCodeCamp 49-hour** video, plus relevant LeetCode problems
    - `*.java` — solutions with comments on time/space complexity
    - `README.md` — topic covered, key takeaways, what to revisit

## Progress Tracking

See [`PROGRESS.md`](./Progress.md) for a log of patterns covered, problems solved (independently vs. with help), and rough timing — kept separate from the topic-based solution folders since it tracks *pace and readiness* over time, not just topic coverage.

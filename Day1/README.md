# VDB_DSAConquest

Personal DSA practice repo, following along with the freeCodeCamp 49-hour Data Structures & Algorithms course.

Organized by day (`Day1`, `Day2`, ...), each folder containing the problems tackled that day plus notes on approach and complexity.

## Structure
- `DayX/` — one folder per study session
    - `*.java` — solutions with comments on time/space complexity
    - `README.md` — topic covered, key takeaways, what to revisit
